# Analysis Protocol

**Protocol version:** 1.0  
**Status:** Active  
**Effective date:** 2026-08-27    
**Project:** The Sieve of Theophrastus

---

## 1. Purpose

This document defines the procedures used to produce analyses share in the
project repository, based off of The Sieve of Theophrastus dataset.

The purpose of the protocol is to make clear what was used to generate the
charts in the analysis folder:

- The Sieve of Theophrastus dataset;
- existing published reference located by search engines or AI assistants;
- conversion of data tables into charts via appliations or AI assistants.

This protocol applies to charts in the analysis folder.

---

## 2. General principles

Chart creation from The Sieve of Theophrastus dataset is the primary case, and
this uses well-known methods, such as graphing rows or columns over time.

For some charts, it is desired to try to include external reference data, and
in these cases search engines will be used to locate published data.

It is not the intent of the protocol to plagarize, there should be a file 
accompanying each analysis or set of analyses using the same reference data 
that contains the reference sources.

# 3. Protocol revisions

This protocol is versioned.

Changes to the protocol are documented rather than silently applied to
historical measurements.

| Version | Date | Change |
|---|---|---|
| 1.0 | 2026-08-27 | Initial protocol |
| 1.1 | YYYY-MM-DD | [Description] |

Historical analyses retain the protocol version under which they
were generated where practical.
